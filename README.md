# DOMOSOLUCES Equipement

Firmware et banc de prototypage des équipements DOMOSOLUCES.

## Prototype
Keyestudio Smart Home sert de banc matériel. Les drivers/GPIO sont isolés derrière une couche d'abstraction afin que le contrat IoT reste identique au produit industriel.

## Confidentialité usine
Ce dépôt est la propriété logicielle DOMOSOLUCES. Il ne constitue pas un livrable usine. Aucun secret de production ne doit être commité. Les documents fabricant seront séparés du firmware propriétaire.

## Etat
Initialisation contrôlée par le LEAD. Développement sur develop après contrat IoT V1.
